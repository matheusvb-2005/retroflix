# RetroFlix 🎮

Plataforma de streaming com estética retrô / pixel art, desenvolvida como trabalho A3 da disciplina de Banco de Dados II.

Projeto apresentado em **junho de 2026**, avaliado com **nota máxima** após a explicação técnica e de contexto.

## Tecnologias

- **Node.js** + **Express**: servidor e API REST
- **MongoDB** + **Mongoose**: banco de dados NoSQL e modelagem
- **HTML, CSS e JavaScript** puros no front-end
- **dotenv** e **CORS**

## Como rodar

```bash
npm install
cp .env.example .env
npm run seed
npm start
```

Acesse `http://localhost:3000`.
